# 🎹 Build-A-Piano 

## Overview

This project is a one-octave interactive piano built using **HTML, CSS, and JavaScript**. It allows users to play notes by clicking the keys or pressing corresponding keyboard keys. Additionally, the project features a **'Twinkle Twinkle Little Star' melody player** that automatically plays the song while highlighting the pressed keys.

## Features

✅ Fully functional **one-octave** piano layout  
✅ **Mouse and keyboard interactivity** for playing notes  
✅ **Smooth CSS styling** with correct black key placement  
✅ **Real-time visual feedback** when keys are pressed  
✅ **Extra credit**: Automated **'Twinkle Twinkle Little Star'** melody player  
✅ **Mobile-responsive design**  

## 📂 File Structure

- `index.html` - Contains the structure of the piano  
- `styles.css` - Defines the styling for the piano layout  
- `script.js` - Adds interactivity, sound playback, and the melody player  

## 🎵 How to Use

1. **Play Notes**  
   - Click on the keys to play individual notes.  
   - Use your keyboard (`Z-M` for white keys, `S-D-G-H-J` for black keys).  

2. **Play Twinkle Twinkle Little Star**  
   - Press the **"Play Twinkle Twinkle"** button to hear the song play automatically.  
   - Watch the keys light up in sync with the melody.

## 🚀 Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_GITHUB_USERNAME/Build-A-Piano.git
   cd Build-A-Piano
   ```
2. Open `index.html` in your browser or use **Live Server** in VS Code.
